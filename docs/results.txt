Run 1

The generation component was evaluated using ROSCOE-SS (facebook/roscoe-512-roberta-base), a reasoning-oriented semantic similarity metric. For each generated proposition, we compute the cosine similarity against all available annotator reconstructions for the corresponding tweet (up to three), scale the scores to the [0, 1] range using the formula (1 + cos) / 2, and take the mean across references as the final per-sample score. We report two metrics: matched-only, which averages scores only over tweets for which both a system generation and a gold reference are available, and with zeros, which assigns a score of 0 to cases where a gold reference exists but no generation was produced, or where a generation was produced for a tweet without a gold reference.
